Protocole de résolution

Chaque symbole apparaît exactement une fois par ligne et par colonne, dans chaque époque. Le rang des symboles est indiqué sur les boutons de placement (1, 2, 3…).

Les petits signes comparent toujours les deux cases de même position : Passé < Futur (rang croissant), Passé > Futur (rang décroissant), Passé = Futur (même symbole). Un signe absent n'impose aucune liaison. Les deux époques sont nécessaires à la résolution.

Clique sur une case puis sur un symbole. Clavier : chiffres, flèches, Suppr et N pour les annotations. Les indices colorés d'origine sont verrouillés.
